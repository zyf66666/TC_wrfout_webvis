绘图参数（只读展示）

Basic
Python 自定义绘图
默认环境：conda: wrf-webvis · 输出：PNG

读取网站所在机器上的数据，相对路径以项目根目录为基准。创建一张 Matplotlib 图即可自动收图；其他绘图库请将 PNG 保存到 OUTPUT_PATH。DPI 是当前设置的输出分辨率。

Variables
plot variables
on name type cmap/color (blank = preset experiment color) levels extend sigma scale advanced
quiver variables
on name color interval scale factor

levels can be written as 10|15|20, 10:51:5, or np.arange(10,51,5). Disabled rows are kept but not drawn.

Selection

Selection accepts 0,1,2, 0|1|2, 0:120:1, np.arange(120), np.arange(0,120,1), or 0h5min. Colon ranges include the end value; np.arange keeps its usual exclusive end.
