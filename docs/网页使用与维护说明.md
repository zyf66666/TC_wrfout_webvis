# WRF WebVis 使用与维护说明

本文说明独立运行的 WRF WebVis：看板、绘图、处理数据 v3、后台任务和账号。仓库不含真实模拟数据；需要自行提供 `wrfout` 或已处理的 NetCDF 数据。

## 安装与启动

在 Python 虚拟环境安装依赖：

```bash
python -m pip install -r requirements-web.txt
python -m pip install -r requirements-processing.txt
python -m uvicorn wrf_webvis.app.main:app --host 127.0.0.1 --port 8000
```

已有数据的网页查看和绘图依赖 `requirements-web.txt`；数据管理中的处理任务还需要 `requirements-processing.txt`。启动后访问 <http://127.0.0.1:8000/>。

### 数据路径

路径环境变量在 `wrf_webvis/app/core/config.py` 中读取，均可用绝对路径覆盖：

| 环境变量 | 用途 | 未设置时的默认值 |
| --- | --- | --- |
| `WRF_WEBVIS_EXPERIMENTS_ROOT` | 原始试验目录 | `/Volumes/WRF` |
| `WRF_WEBVIS_PROCESSED_ROOT` | 网页绘图使用的 v3 数据根目录 | `/Volumes/land_1/processed_v3` |
| `WRF_WEBVIS_LEGACY_PROCESSED_ROOT` | 旧版处理入口默认输出目录 | `/Volumes/land_1/processed_v2` |

处理数据 v3 的试验源目录、输出目录及科学参数以 `处理数据_v3/project_config.py` 为准；这些配置与网页绘图数据根目录分别管理。不要在绘图时假设系统会自动处理缺失数据。绘图读取已完成的 v3 切片。

## 看板、图片与批注

看板和用户数据放在 `wrf_webvis/storage_data/`（运行时生成，不应提交到代码仓库）。看板数据库保存看板层级、图片记录、图上批注、文字批注及最近删除记录。生成的图片位于 `wrf_webvis/app/static/figures/`，关联的坐标信息文件用于图上批注定位。

看板最多两级。图片可以在看板间移动，权限取决于登录用户。备份时同时保存 `storage_data/` 和 `app/static/figures/`，并在恢复后检查图片文件与数据库记录是否对应。

## 账号与访问

访问策略由 `wrf_webvis/app/core/access.py` 实现。管理员通过账号管理创建用户并授予看板查看、批注、绘图或数据管理等权限。用户和会话数据保存在 `storage_data/users.sqlite`；不要把数据库或密码材料放入 git。

首次部署时，先在受信任的本机环境启动服务并设置管理员账号，再配置反向代理提供 HTTPS。公网入口应正确传递代理地址头，并确认未登录访问会进入登录流程。反向代理及 TLS 配置需按部署环境单独完成；不要直接把开发服务器暴露到公网。

## 处理数据 v3、绘图和后台任务

处理数据 v3 是独立的处理管线，入口为 `处理数据_v3/process_data.py`，网页接口位于 `wrf_webvis/app/api/processing_v3.py`。命令行默认仅预览，执行需明确使用 `--run`。网页数据管理页可检查输入和已处理数据覆盖、预览依赖、提交任务并查看进度。处理任务可能占用大量存储和计算资源，运行前确认输入、输出位置和可用磁盘空间。

网页绘图通过 `wrf_webvis/app/api/plots.py` 和 `app/plotting/` 生成图像；看板通过图片接口保存和展示图像。绘图只读取 processed_v3 切片，不负责重算或补齐切片。任务记录和应用状态位于 `storage_data/`。

## 测试与维护

标准 Python 测试目录为 `wrf_webvis/tests/` 与 `处理数据_v3/tests/`：

```bash
python -m pytest wrf_webvis/tests 处理数据_v3/tests
```

仓库另有 Node 前端测试，可运行 `node --test wrf_webvis/tests/*.mjs`。Python 测试需设置模块搜索路径，例如 `PYTHONPATH=wrf_webvis:处理数据:处理数据_v3 python -m pytest wrf_webvis/tests 处理数据_v3/tests`。测试依赖当前安装的 Python 和 Node 环境。

网页运行日志位置取决于启动方式。使用 uvicorn 前台启动时查看终端输出；使用服务管理器时检查其配置的标准输出和错误日志。修改路径或部署配置后，重启网页进程并确认首页、登录、看板、绘图和数据管理页可访问。

建议定期备份 `storage_data/`、`wrf_webvis/app/static/figures/` 和 `处理数据_v3/project_config.py`。恢复时先保留现有目录副本，再核对数据库和图片文件。

| 图像生成 | `wrf_webvis/app/plotting/` |
| v3 处理管线 | `处理数据_v3/` |
